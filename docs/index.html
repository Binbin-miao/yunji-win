什么是云姬电脑版？

云姬电脑版（也叫云姬 Windows 版、云姬 PC 版）是一个非官方的开源桌面移植工具。 官方云姬 App 只提供安卓手机端，Windows 用户在电脑上连接 Type-C 解码耳放（俗称「小尾巴」）时，往往无法调节设备内置的 DSP 参数。 本项目基于对设备通信协议的逆向分析与自研实现，把手机上的调音能力完整搬到了 Windows 桌面端。

它支持 TTGK 与 旋润 两大品牌阵营的硬件协议，可直接读写设备固件参数并保存，全部操作在本机完成，不依赖任何厂商服务器。

核心功能

🎚️ 参数均衡器 ProEQ

8 段双二阶（Biquad）峰值均衡，实时频响曲线拟合，可逐段调整频率、Q 值与增益，一键写入硬件 DSP 并生效。

🎛️ 简易均衡器 EZEQ

音乐 / 游戏双模式，8 个特征旋钮配合随机调音模板，不懂参数也能快速调出满意的听感。

🔊 DAC 与硬件参数

硬件音量、麦克风输入增益、左右声道平衡、高 / 低增益档位、5 档数字滤波器、LED 指示灯开关。

🔌 免驱即插即用

TTGK 阵营利用 Windows 原生 HID 驱动直通，无需安装 WinUSB 或任何第三方驱动，插上就能识别。

🔄 热插拔自动侦测

设备拔出自动回列表，重新插入自动识别并同步当前硬件参数状态，无需重启软件。

🧩 开源可扩展

MIT 许可证开源，协议实现完全公开，欢迎提交新设备适配与功能 PR。

支持设备

  • TTGK 阵营：凌云剑、Q25 等（CB1200 / CB5100 架构）—— USB HID 中断传输，Windows 原生免驱。
  • 旋润阵营：YUNJI43198PRO、YUNJI43198ULTRA、You Got Me 等 —— USB 控制传输。

若你的设备不在列表内，欢迎在 Issues 提交设备信息协助适配。

下载与安装

  1. 前往 Releases 发布页 下载 YunjiSettings-v1.7.5-win64.zip。

cd yunji-win
pip install -r requirements.txt
python app/main.py

常见问题

云姬电脑版是官方软件吗？

不是。本项目是独立开发者出于学习与跨平台便利性所做的非官方开源移植，与任何音频硬件品牌官方均无商业合作或授权关系，相关商标归原权利人所有。

需要安装驱动吗？

TTGK 阵营设备使用 Windows 原生 HID 驱动，无需额外安装；旋润阵营设备如未识别，可参考仓库 README 中的驱动说明。

会修改我的设备固件吗？

软件只会按你的操作读写设备的可配置参数（音量、EQ、滤波等），不会刷写固件。所有写入操作都需要你主动点击保存。
