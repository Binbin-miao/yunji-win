# 网页版 HID 帧构造（真机已验证）

> 验证环境：凌云剑（`0x3302:0x43EC`），Chrome 桌面版 + WebHID，2026-10-31。
> 本文只记录「怎么在浏览器里正确发帧」，不是完整协议文档；协议本身见 `docs/协议参考.md`。

## 帧构造（唯一正确写法）

```js
// 负载 = 去掉首字节 0x4B 后的协议帧，补零到 63 字节
await device.sendReport(0x4B, payload63);
```

- **报告 ID 是独立参数，不能出现在负载里。** 桌面版 hidapi 的写缓冲首字节是报告 ID（`4B 80 0C …` 共 64 字节），WebHID 里必须拆成 `reportId=0x4B` + `负载=[80 0C …]`（63 字节）。
- 写成 `sendReport(0x4B, [0x4B, 0x80, 0x0C, …])` 会让设备收到 `4B 4B 80 0C`，**设备不报错、直接不响应**——这是最容易被误判成"设备不支持"的坑。
- 负载长度按描述符推导：`reportBytes = ceil(Σ(reportSize × reportCount) / 8)`，实测 63。

## 收帧

响应以 **input report** 到达，`event.reportId === 0x4B`，`event.data` 去掉报告 ID 后即协议帧：

```js
device.addEventListener('inputreport', ev => {
  const full = new Uint8Array([ev.reportId, ...ev.data]); // 还原成 [4B, 80, CMD, ...]
  // 校验 full[0]===0x4B && full[1]===0x80 && full[2]===cmd
});
```

`FEAT` 通道为空，feature report 走不通，不必再试。

## 设备暴露的报告

```
OUT 0x4B:63B  0x54:63B
IN  0x03:63B  0x4B:63B  0x54:63B
```

`IN 0x03` 是系统音量键那条标准通道，与协议无关；`0x54` 未使用。

## 实测响应

| 命令 | 请求负载（去掉报告 ID） | 响应（去掉报告 ID） | 说明 |
| :--- | :--- | :--- | :--- |
| 固件 0x0C | `80 0C` | `80 0C 00 30 2E 38` | `0.8` |
| 音量 0x03 | `80 03` | `80 03 02 00 00` | 值在 `[4:6]`，LE，除以 256 |
| 麦克风 0x02 | `80 02` | `80 02 02 00 12` | 0x1200/256 = 18 |
| 滤波 0x11 | `80 11` | `80 11 00` | 值在 `[4]` |
| 增益 0x19 | `80 19` | `80 19 00` | 值在 `[4]` |
| 指示灯 0x18 | `80 18 01` | `80 18 01 00` | `[4]` 回显 arg，`[5]` 为值？待核 |
| 平衡 0x16 | `80 16 04 00` / `80 16 04 01` | `80 16 04 00 …` / `80 16 04 01 …` | **`[4]` 回显 arg，校验可以加** |
| EQ 段 0x09 | `80 09 18 <index>` | `80 09 18 00 …` | 长度 0x18=24，可读回 |

另：`[3]` 位置是负载长度字段（如 `02` 表示随后 2 字节是数值），与桌面版 `resp[4:]` 的取值偏移一致。

## 参数语义（易错，务必按芯片换算）

设备返回的是 **DAC 原始值**，不是百分比。桌面版还有一层映射，网页版必须照搬，否则显示全错：

| 参数 | 原始值范围 | 显示值 | 依据 |
| :--- | :--- | :--- | :--- |
| 音量（cb5100，如凌云剑） | −60 … 0 | 原始值 + 60 → 0 … 60 | `TTGK_MIN/MAX_DAC_VOL`、`TTGK_DAC_VOL_OFFSET` |
| 音量（cb1200，如 Q25/云中剑） | −8 … +4 | 原始值 + 0 → −8 … +4 | 同上 |
| 麦克风 | −30 … 30 | **原始值本身** | `mic_row.value_fmt = v - 30`（滑杆位置 +30，显示不 +） |
| 声道平衡 | −20 … 20 | **原始值本身** | `bal_row.value_fmt = _bal_text(prog)` → `prog - 20` |

> 实例：凌云剑读回音量 `0x0000` 不是"音量 0"，而是 **最大档（显示 60）**。按百分比显示会把最大音量画成静音。
>
> 注意桌面版的 `SliderRow`：`set_value(raw + 30)` 设的是**滑杆位置**，显示文字由 `value_fmt` 再减回去。只看 `set_value` 会误以为显示值加了偏移。

## 危险命令（真机实测）

| 命令 | 现象 | 处理 |
| :--- | :--- | :--- |
| `01 1E 01 00` | 设备进入**红灯闪烁**（错误/复位态），需拔插复位后才恢复黄灯→蓝灯 | **严禁发送** |
| `01 1D 01 <v>` | 写入可被接受，回读跟随，灯无可见变化，语义未知 | 不主动使用 |
| `01 18 01 <v>` | 值能写入并存住（回读跟随），但**机身灯完全不响应** | 网页版只读，不写 |
| `01 54 ...` | 0x54 通道对灯无效 | 不使用 |

## 待核对
